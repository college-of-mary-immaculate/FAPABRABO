Backend (Python):
- FastAPI (API framework)
- Uvicorn (ASGI server)
- Pydantic / pydantic-settings (config & validation)
- NumPy, Pandas (data handling)
- PyMongo (MongoDB client)
- python-dotenv (env management)
- Starlette (FastAPI underlying)
- anyio, h11, sniffio (ASGI stack deps)

NLP Core (Python):
- Custom preprocessing (tokenization, normalization, stopwords) in core/utils/preprocess.py
- N-grams model in core/ngrams
- Naive Bayes classifier in core/naivebayes
- TF-IDF representation and cosine ranking in core/tfidf/representation_tf.py

Datasets:
- CSV/JSON under BackEND.gg/datasets/

Frontend (Web):
- React 19, React DOM
- React Router DOM 7
- Vite 7 (build/dev)
- TypeScript 5
- ESLint 9 (+ react-hooks, react-refresh)

Scraper (Node.js):
- Puppeteer (browser automation)
- Cheerio (HTML parsing)
- csv-parse, json2csv (data transforms)

Infrastructure/Other:
- MongoDB (vector store and metadata)
- CORS configuration for API
