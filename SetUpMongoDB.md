# 🧩 MongoDB Community Edition Installation Guide

## 🔗 Official Website
Visit the official MongoDB website:  
👉 [https://www.mongodb.com/](https://www.mongodb.com/)

---

## 📚 Step 1: Open the Server Documentation
1. Hover over **Resources → Server Documentation**  
2. Navigate to:


📸 **Screenshot:**
![Server Documentation](https://github.com/user-attachments/assets/0baa76dc-3c6d-4bdd-9cc5-584175d2b6a5)

## 💾 Step 2: Open the MongoDB Download Center
Click the **MongoDB Download Center** link.

📸 **Screenshot:**
![MongoDB Download Center](https://github.com/user-attachments/assets/e1b2a704-466b-489e-9050-ae35d022b4f2)

You’ll find several tools available under the **Tools** tab:

- 🧩 **MongoDB Shell (mongosh)**  
- ⚙️ **MongoDB Database Tools**  
- 🧭 **MongoDB Compass** *(optional GUI tool)*  

➡️ For this setup, click **MongoDB Community Server**.

📸 **Screenshots:**
![MongoDB Shell](https://github.com/user-attachments/assets/e0ce87a6-902e-43d8-b94d-b933eb396dee)
---

## ⚙️ Step 3: Download MongoDB Community Server
1. Select your platform (e.g. **Windows**).  
2. Choose the **MSI Installer Package**.  
3. Click **Download** to begin.

📸 **Screenshot:**
![Download MongoDB](https://github.com/user-attachments/assets/9f933969-5caf-4f9b-96c8-6665cdc0ebbd)

---
## 🧰 Step 4: Install MongoDB
Follow the installation wizard:

1. Open the downloaded `.msi` file.  
   ![MongoDB Community Server](https://github.com/user-attachments/assets/375cb777-2c18-4394-a647-48e7f78dc2b7)

2. Click **Next**.  
   ![Setup Next](https://github.com/user-attachments/assets/217e2a60-6294-440d-b439-b7b20b9e976b)

3. Accept the **License Agreement** → click **Next**.  
   ![Accept License](https://github.com/user-attachments/assets/039cf471-fed0-4a5f-8ce0-e185b4a35871)

4. Choose **Complete** setup type → click **Next**.  
   ![Complete Setup](https://github.com/user-attachments/assets/aa4abd36-93d5-417f-9442-61340a9fdd74)

5. Proceed with the installation → click **Next**.  
   ![Installation Next](https://github.com/user-attachments/assets/cb7d3ffc-eae6-48b4-8d84-552bd232bb60)
6. Continue with the installation → click **Next**.  
  ![Installation Next](https://github.com/user-attachments/assets/cb7d3ffc-eae6-48b4-8d84-552bd232bb60)
